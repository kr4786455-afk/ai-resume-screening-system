# AI Resume Screening System
A beginner-friendly AI resume screening app built with Python and Streamlit.
Features:
- Upload resume PDF
- Detect skills from resume
- Select job role
- Calculate match percentage using TF-IDF and cosine similarity

Tech Stack:
- Python
- Streamlit
- NLP
- TF-IDF
- Cosine Similarity
- scikit-learn
- pypdf
  
 How to Run :

```bash
pip install -r requirements.txt
streamlit run app.py
